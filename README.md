# Content Design

An open Qentrah agent skill for writing clear, concise, product-ready interface copy.

## Goal

Make product language understandable, consistent, and ready for translation.

## Install

```bash
npx @qentrah/skills add content-design
```

- `SKILL.md` — the portable instructions consumed by an AI agent.
